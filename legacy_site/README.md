## 🔧 Setup & Deployment

### Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/DataVaultAI.git
   cd DataVaultAI
   ```

2. Open in browser:
   ```bash
   # Using Python's built-in server
   python3 -m http.server 8000

   # Or using Node.js http-server
   npx http-server

   # Then visit http://localhost:8000
   ```

3. Edit content:
   - Modify `index.html` for content changes
   - Update `css/style.css` for styling adjustments
   - Customize `js/script.js` for interactive features

### Production Deployment

The website can be deployed to:

- **GitHub Pages**: Push to `gh-pages` branch
- **Netlify**: Connect repo and deploy automatically
- **Vercel**: Import project and deploy
- **AWS S3 + CloudFront**: Static hosting with CDN
- **Azure Static Web Apps**: Enterprise-grade hosting
- **Traditional Web Hosting**: Upload files via FTP/SFTP

### Recommended Deployment Steps

1. **Add Custom Domain**: datavalutai.co.uk
2. **Enable HTTPS**: Essential for trust and SEO
3. **Configure CDN**: For fast global delivery
4. **Setup Analytics**: Google Analytics or privacy-focused alternatives
5. **Add Contact Form**: Integrate with backend or service (Formspree, Netlify Forms)
6. **Optimize Images**: Compress and use WebP format
7. **Enable Caching**: Configure browser caching headers

1. **Logo**: Replace emoji logo with actual logo image in `index.html`
2. **Contact Details**: Update email, phone, address in Contact section
3. **Company Registration**: Add actual UK company number in footer
4. **Social Media**: Add social links to footer (currently not included)

Replace fictional case studies with actual client work:
1. Obtain client permission
2. Replace content in Portfolio section
3. Update metrics with real data

### Customize Colors

Update CSS variables in `css/style.css`:
```css
:root {
    --primary-dark: #YourColor;
    --accent-blue: #YourAccent;
    /* etc. */
}
```
